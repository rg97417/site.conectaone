### **Método 2: Box "Leia Também" (Complementar)**

Adicionar ao final de cada artigo:

```tsx
// src/components/RelatedArticles.tsx

interface RelatedArticle {
  title: string;
  slug: string;
  category: string;
}

interface RelatedArticlesProps {
  articles: RelatedArticle[];
}

export function RelatedArticles({ articles }: RelatedArticlesProps) {
  return (
    <div className="mt-12 p-6 bg-gray-50 rounded-lg border-l-4 border-blue-600">
      <h3 className="text-xl font-bold mb-4">📚 Artigos Relacionados</h3>
      <ul className="space-y-3">
        {articles.map((article) => (
          <li key={article.slug}>
            <a
              href={`/blog/${article.slug}`}
              className="text-blue-600 hover:text-blue-800 font-medium"
            >
              → {article.title}
            </a>
            <span className="text-sm text-gray-500 ml-2">({article.category})</span>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

## ⚠️ Avisos Importantes

### **NÃO Fazer:**
❌ Links genéricos ("clique aqui", "saiba mais")
❌ Mais de 10 links internos por artigo (spam)
❌ Links forçados sem contexto
❌ Links em rodapé/sidebar (Google desvaloriza)
❌ Links recíprocos excessivos (A→B, B→A)

### **FAZER:**
✅ Anchor text descritivo e variado
✅ Links naturais ao fluxo de leitura
✅ Priorizar pillar pages (recebem mais links)
✅ Mix de links para artigos do mesmo cluster + outros clusters
✅ Atualizar artigos antigos com links para artigos novos
